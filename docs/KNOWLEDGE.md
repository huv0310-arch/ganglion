## 1. 接线八步配方（判据一字不动，只换壳）

1. `cp` 正本 `ganglion.py` 到目标 `scripts/`
2. 动刀前备份：`cp front_door.py front_door.py.bak_ganglion_std_<YYYYMMDD>`
3. import 区后加接入块：`try: from ganglion import Ganglion as _StdGanglion except Exception: _StdGanglion=None`（fail-open 第一层）
4. 写 `_ganglion_check`：闭包包住**原判据函数**，返回 `(1, reason) if hit else (0, "上行")`
5. main() 调用点换成标准件入口，**原内联判据保留为 except 回退**（第二层）
6. 记忆落盘到 `os.path.join(os.path.dirname(JOURNAL), "ganglion_mem_fd.json")`
   —— 钩子每消息起新进程，**不落盘 = 白装**（进程内存活不过一条消息）
7. 落盘前清理：只留 TTL 内 + 最近 500 条
8. `python -m py_compile` 过了才算接完，再跑对照回归

## 2. 插点判据：什么地方够格挂骨节

**签名**：一个 content 进，两个值出（verdict + reason）。四条全中才装：

| # | 判据 | 反例（不装） |
|---|------|--------------|
| 1 | **判据纯靠内容**：同文必同判 | 挂活变量（时间/账本/阈值/器官历史摘要）的判决——同文异判是它的本分 |
| 2 | **高频复判**：同一 content 反复进同一判据，装前先翻日志数复判段 | 281 轮日志只有 2 轮异常（0.7%），拍脑袋不算高频 |
| 3 | **判决可两值化**：verdict+reason 能冻结回放 | 生成型会话、需要新鲜上下文的第二意见 |
| 4 | **有模型调用或一致性价值**：省 token，或防判据忽松忽紧 | 0 模型调用的纯正则——省不出东西，还多一台收银机 |

**最硬的一句**：装得下 ≠ 该装。免费正则能干的活它一样装得下，
**同一句邀请，拒绝十次的人才配装对那一次。**

## 3. 验死存档（真账回放，别再重测）

### 3.1 4B 仲裁缓存：0.7% 命中，判死
- 6224 条真账、1961 次开火回放。
- **方案 A**（key = 组装完的完整仲裁 prompt，含档位结账尾）：命中 **0.7%**。
  账挂尾每来一条同器官消息就变一次，key 每轮都动，天生饿死，无限 TTL 无救。
- **方案 B**（只留消息 key，丢账尾）：命中 **22.9%**，但缓存判决 vs 实际判决
  **tier 一致率只有 89.8%**（「你好呀」small→medium、 「8091还活着吗」powerful→small）。
  **仲裁 = 带新鲜账的第二意见，喂陈旧判决 = 拆台**，而 trade 还在里面。
  → 维持裸奔。
- **安装坑**：标准件 `_make_key` 剥噪取**前 64 字符**——长 prompt（模板头固定）会全员撞格，
  第一次判决灌给所有消息。长 prompt 要么自己 sha256 全文当 content 传，要么别装。

### 3.2 Laya 首判复读缓存：21% 命中，一致率 82%，判死
剥噪前 150 字符做 key，10 分钟窗复读命中 21%，但 tier+organ 一致率仅 82%。
和 4B 一个病：**复读 ≠ 同判**。缓存=喂陈旧判决拆台，不装。

### 3.3 反面教训：97.9% 的浪费是「进错门」不是「重复判」
L2 判决流 3410 条里 3317 条（97.9%）是免疫台账行——记忆记账不是信号，判它们 = 白烧。
**找省 token 的地方，先量「判决流各类占比」，再想缓存。**
缓存救不了进错门的，滤网才救得了。（→ peanut_gate.py 总线滤网，判决量 3410→93）

## 5. 三个变体（同族同签名，方向不同）

| 变体 | 方向 | 用途 |
|------|------|------|
| 前门骨节 | 拦（1 拦 / 0 放行） | 反射闸判据加记忆，同句 TTL 内免重扫 |
| 回声闸骨节 | 拦 | 机器罐头句识别，三家网关共用一本账 |
| **心跳骨节 `ganglion_speak`** | **开口（判 1 就叫嘴说话）** | 每跳免费翻两本账，翻到才唤醒模型；没翻到=空输出=0 token |

心跳骨节的关键三件：
1. **输出必须确定性**（料里禁相对时间，否则 monitor 每 tick 判变化 = 刷屏）
2. **冷却 + 日封顶 + spent 轮转**（防自产自销）
3. **fail-open 结果绝不落盘**（降级不冻结——「我没判出来」不许写成「我判它是第一句」）

## 6. 踩坑清单（全是真事故，不是假设）

1. **key 必须掺 platform/namespace**：标准件只哈希内容。`f"{platform}::{msg}"` 编进 key，
   否则 desktop 命中的缓存漏进 cli 通道，绕过「cli 不走反射闸」铁律。串门 bug 2026-10-29 抓于协作者 B门。
2. **reason 带全 cause**：记忆翻书回来要能还原原判据输出的每个字段（如「心跳探针(cron)」的 `(cron)`），
   不然对照回归抓不住漂移。
3. **.bak 后缀测不了**：importlib 对非 `.py` 后缀返回 `spec=None`，回归测试先 cp 成临时 `.py`。
4. **记忆必落盘 + 落盘前清理**：进程内存活不过一条消息；只留 TTL 内 + 最近 500 条。
5. **fail-open 三层**：缺件 / 烂记忆文件 / check 异常 → 全部退回内联原判据，**坏件不坏门**。
6. **fail-open 的结果绝不许落盘**：本体 63-67 行异常直接 return 走不到写记忆那行，
   传染源都在各人自己写的肉里抄漏。
7. **嘴不许有第二道否决权**：静默是骨节的权力。提示词写「你能醒来 = 骨节已判 1，禁止输出 [SILENT]」。
8. **部分批绝不许当完整批落盘**：只在 `len(got) == len(todo)` 才落 key，否则漏判的文件永远卡死。
9. **自检必须用真账形状**：真账全是 `- ` 列表行 + `# 标题`；新造测试文件 mtime 是今天，必须 `os.utime` 拨老。
10. **推理模型要关思考**：否则 token 全烧在 reasoning、正文空、判决本永远空
    ——必须 `chat_template_kwargs.enable_thinking=false`（顶层无效）。
