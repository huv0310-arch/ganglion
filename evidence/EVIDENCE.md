**改日期不动任何指纹**：三枚哈希的值与图的排版无关。旧图仍在 SWH 存档里，永远取得回来——这正是"只追加、不抹掉"的做法。

**改动任一字节，三枚指纹同时失效。** 复现：

```bash
sha256sum ganglion.py                     # 应得 SOURCE
python -c "import hashlib;a='<SOURCE>';b='<PAPER>';print(hashlib.sha256((a+b).encode()).hexdigest())"   # 应得 COMBINED
```

> 注意拼接规则：**十六进制字符串直接相连**，不是字节相连、也不是换行相连（后两者算出的值不同，已实测）。

### 三枚指纹的复算状态（分别报，不许合并成一句"已通过"）

| 段 | 能否复算 | 依据 |
|---|---|---|
| SOURCE | ✅ **可复算** | `sha256sum ganglion.py` = `7afe4b7f…38f047`，105 行 / 3804 字节，2026-11-01 实算复核 |
| COMBINED | ✅ **可复算** | 但输入是**声明的 PAPER 十六进制串**，不是论文本身；方法自洽，地基是下面这一环 |
| PAPER | ❌ **不可复算** | 输入原件未随仓库保存。四方独立尝试合计 **8 + 94 + 299 + 76 = 477 种**写法（DOI 各形态、标题、日期、换行、UTF-16、组合顺序），0 命中 |

**PAPER 这一环的性质**：它是引用标记，不是原创证明。对第三方论文取哈希，对"谁先做出来"零贡献——论文 published 在前，绑它进来只增加噪音。本版不改它的值（改值 → COMBINED 变 → 图作废 → 与 SWH 存档对不上），**如实标注，等下一版换层时再解耦**。
